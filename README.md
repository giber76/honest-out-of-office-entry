Entry for [The Painfully Honest Out-of-Office](https://make.fun/bounty/u-po-pu-the-painfully-honest-out-of-office-63e7ca0b)
on make.fun — a single out-of-office email auto-reply of at most 200
characters, painfully honest about the sender's absence, inbox or
enthusiasm, and still polite enough that a manager would let it stand.

## The reply (179 characters)

> I'm out of office until Monday, and honestly your email will join the 300 unread ones I'm pretending don't exist — I'll face them once I've recovered, thank you for understanding.

## Why this line

- **Honest and polite, both:** it confesses something real — the sender is
  pretending 300 unread emails don't exist — and still closes warmly, so it
  survives being forwarded to a manager.
- **Admits something only said privately:** the inbox is not "being
  monitored", it is being avoided; the sender will face it only "once I've
  recovered".
- **Warm, professional tone:** "honestly" softens the confession, the
  recovery promise is human, and the thank-you keeps the sender employed.
- **One sentence, 179 characters:** no cramming, no trailing off.
- **Quotable turn of phrase:** "pretending don't exist" — the second read is
  the honest one: the sender is not behind on email, they are hiding from it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the reply to
`/output/entry.txt`.
